## 1. 소부장

### 1-1. 테스 — 수주잔고와 신규 장비(BSD·Tetra) 옵션

**증권사 시각**

- **SK증권, 2Q26 Review / TP 23만원(유지)**
  - 2Q26 신규 수주 2,823억원, 전분기 대비 2배 증가
  - 수주잔고 고려 시 하반기 실적 컨센서스 상회 여지
  - 쌓이는 수주잔고 흐름 자체가 주가의 중요한 트리거 포인트
- **삼성증권, 2Q26 Review '안팎으로 좋다' / TP 20만원(상향)**
  - 연구개발비 일시 증가로 영업이익은 컨센서스 부합
  - 모든 고객사의 증설 가속화 속 BSD 장비 매출 기여 확대에 주목
  - TP는 2027년 PER 30배 적용(글로벌 전공정 장비 점유율 상위 5개사 평균 30배)
  - 과거 테스는 제한적인 제품 포트폴리오와 높은 NAND 의존도로 동종업계 대비 할인 거래

**2Q26 요약**: 매출은 서프라이즈, 이익은 일회성 비용(R&D) 영향.

**수주 → 실적 경로**

```
2Q말 수주잔고 2,000억원+
  → 대부분 연내 매출 인식 가능
  → 3Q26부터 상반기 수주 본격 매출화
  → 하반기 추가 수주까지 반영
  → 연간 실적 컨센서스 상향 가능성
```

**전방 투자**: 삼성전자 P4 → PH4, NAND는 시안 및 V9 전환 투자 / SK하이닉스 M15X DRAM 투자 지속. **DRAM + NAND 동시 수혜**가 테스의 강점.

**신규 장비 ①: BSD(Backside Deposition) — 더 중요한 쪽**

- 웨이퍼 뒷면에 막을 입혀 휘어짐(Warpage)을 잡아주는 장비
- HBM·고단화 NAND처럼 웨이퍼가 얇아질수록 휘어짐 문제가 커짐
- 뒷면에 SiO/SiN 등을 증착해 앞면과 반대 방향의 응력을 만들어 평탄화
- 따라서 **HBM 고단화 → BSD 필요성 증가**라는 논리. NAND·DRAM·Foundry 모두 적용 가능
- 2025년부터 국내 메모리 고객 NAND 공정에 공급, 현재 HBM용 DRAM 및 다른 메모리 고객의 NAND/Foundry용 퀄리피케이션 진행 중
- 의미: 기존 ACL/ARC가 주로 NAND 투자와 연결됐다면, BSD는 **고객·공정이 DRAM/HBM으로 확장**되는 장비

**신규 장비 ②: Tetra — 고처리량 PECVD**

- Quad chamber 구조로 한 번에 웨이퍼 4장 처리 → Throughput 향상
- SiCN 박막 증착 용도, 국내 메모리 고객 DRAM용 퀄리피케이션 진행
- 기존 장비보다 ASP가 높은 신규 장비로 평가

**'테스만 공급?'에 대한 정리**

- BSD: 테스의 차별화된 신규 장비인 것은 맞지만, 글로벌 시장에서 테스만 만들 수 있는 독점 장비로 보기는 어려움. 중요한 것은 장비의 독점성보다 **삼성전자·SK하이닉스에서 실제 퀄을 통과하고 양산 적용을 확대하느냐**. 공개자료상 국내 메모리 NAND 공급 완료 + DRAM/HBM 확대 평가 중이라는 점이 핵심
- Tetra: 테스 독점이라 볼 근거는 없음. PECVD 범주에서 Applied Materials, Lam Research 등과 경쟁하고 국내에도 증착장비 업체 다수. 다만 의미는 ACL/ARC 중심에서 **DRAM 선단 공정으로 포트폴리오를 확장**한다는 것

### 1-2. 한미반도체 — TCB 지배력 vs 한화세미텍

**2Q26 실적: 확실히 강함**

- 매출 2,511억원(+39.5% YoY), 영업이익 1,303억원(+51.0% YoY), OPM 51.9% — 사상 최대 분기 실적
- 핵심은 **HBM4 양산 본격화 → TC 본더 수요 증가**
- 메모리 업체들이 HBM4E를 올해 말~내년 초 준비하면서 12단·16단용 차세대 TC 본더 수요가 이어질 가능성

**BofA 시각 변화**

- 2월 Neutral → Buy, TP 30만원 → 4월 42만원 → 이후 보도된 전망에서는 50만원 제시
- 하반기 매출 약 5,200억원 예상하며 실적 회복을 강하게 전망
- 논리: ① TCB 시장 지배력 ② 고객 다변화(SK하이닉스 → 마이크론 → 중국 OSAT) ③ 삼성전자 공급 가능성 ④ 용인 SK하이닉스 + 삼성 P5 신규 팹 ⑤ 2028년부터 신규 메가팹의 TCB 수요 본격화
- 밸류에이션: 42만원 = **2028년 EPS × 47배**. 과거 평균 PER 약 60배보다 오히려 낮게 적용했다는 주장("성장성은 2028년으로 보되 배수는 보수적")
- 대조: 상상인 이익추정 기준으로 28년 PER 47배를 적용하면 32만원

**상상인(7/10) '신기록 위에 신사업' / TP 38만원**

- 2027~2028년 예상 평균 EPS 6,057원 × 적정 PER 62.4배(직전 연도 PER 56.7배에 10% 할증)
- 논지: "HBM 하나에만 의존하지 않는다"가 증명되면 시장이 넓어짐
  - 기존: HBM → TC 본더
  - 확장: HBM + Logic + NAND + HBF + 대면적 기판/PLP
- 신규 성장축
  1. **Logic TC 본더** — CoWoS 외주화 확대, OSAT 업체들의 로직용 TC 본더 수요
  2. **HBF TC 본더** — HBF(High Bandwidth Flash), NAND 기반 AI 메모리. 초기 시장이지만 장기 옵션
  3. **MSVP** — 대면적 기판을 자르는 장비, AI 패키징의 Panel Level Packaging(PLP) 확대 수혜로 매출 빠르게 증가
- 결국 밸류에이션 논쟁은 **Logic·HBF·PLP까지 성공한다는 '성장 옵션'을 얼마나 반영할 것인가**

**변수와 리스크**

- 한화세미텍: 과거에는 'SK하이닉스 HBM → 한미반도체 TCB' 구조였으나, 앞으로는 경쟁·공급망 다변화 진행 가능성
- 마이크론 발주, 그리고 **가장 큰 변수는 삼성전자향 수주 여부**
- 시장이 확인하려는 값 = **TCB 시장 성장률 × 한미반도체 점유율**

**그래도 유리한 이유**: HBM3E → HBM4 → HBM4E, 12단 → 16단 이상으로 적층수가 올라갈수록 본딩 정밀도와 생산성이 중요해짐(장비 난이도 상승).

**작업 가정**: HBM4/HBM4E 수요 강함 / 한화세미텍 점유율 상승 / 한미 TCB 점유율 55~60% / 마이크론·중국 고객 증가 / 삼성 공급은 일부 장비부터 / OPM 45~50% 유지.

### 1-3. 원익IPS — 2Q 부진 vs 수주잔고, 그리고 BNK 정점론

**결론**: "2Q 실적은 부진했지만 수주잔고 증가 → 하반기 이익 레벨업"이 주류.

- 8/7 전후 대부분 증권사는 목표주가를 하향하더라도 긍정적 톤 유지(근거: 수주잔고 증가 + 3~4Q 매출 인식 확대)
- **BNK만 차별적 시각**: 전방 수요 둔화 → 주가 정점 통과 가능성
- 현재 논쟁의 핵심은 실적 개선 여부가 아니라 **2027년까지 성장이 지속되느냐**

**왜 주류는 긍정적인가 — 수주가 아직 꺾이지 않았기 때문**

```
1Q 수주잔고 약 4,000억원 → 2Q 신규 수주도 견조
  → 3Q~4Q 수주잔고 매출화 → 하반기 매출·영업이익 증가
```
핵심: **2Q 실적 부진 ≠ 수주 사이클 훼손**

**실적 흐름**

| 시점 | 내용 |
|---|---|
| 1H26 | 수주 증가, 실적은 기대보다 부진 |
| 3Q26 | 수주잔고 본격 매출화, 이익 증가폭 확대 기대 |
| 4Q26 | 매출 증가 + 영업레버리지, 실적 레벨업 여부 확인 |

**2027년이 진짜 승부처**

- Bull: DRAM + NAND + Foundry + CXMT 투자 지속 → 신규 수주 증가 → 2027년 매출·이익 증가 → 현재 밸류에이션 부담 완화
- Bear(BNK): CAPEX 증가율 둔화 → 신규 수주 둔화 → 2027년 이익 성장 제한 → 현재 주가 선반영 부담

**BNK 경고가 중요한 이유**: "실적 개선을 부정하는 것이 아니라, 실적 개선이 이미 주가에 상당 부분 반영됐다." 즉 '수주 증가 → 실적 증가 → 주가 상승'이 아니라 '수주 증가 → 실적 증가 기대 → 주가 선반영 → 이후 CAPEX 둔화' 가능성을 경고. **실적 정점 ≠ 주가 정점**이며, 장비주는 실적보다 주가가 먼저 움직일 수 있음.

**앞으로 딱 3개만 확인**

1. 3Q26 영업이익 증가폭 확대?
2. 4Q26 매출 증가 + OPM 개선 동시 발생?
3. 2027년 신규 수주가 다시 증가?

→ 3개 모두 YES면 주류 전망 우세 / 수주 둔화 + OPM 개선 실패면 BNK 정점론 현실화.

**TP 참고(8/8 리포트)**

- 목표주가 8.8만 / 14만 / 15.3만 / 16.7만 / 19만원, 평균 14.8만원 → 안전마진 30% 적용 시 **10.4~11.8만원**
- 다른 방법: BNK를 제외한 증권사의 26년 이익 50% + 27년 이익 50% 추정치에 PER 20~25배 적용 → 8.4~10.5만 / 9.6~12만 / 9.8~12.2만 / 11.9~14.9만원 산출

## 3. 자동차 · Physical AI — Atlas 포인트

**Atlas, '연구용 로봇' → '공장 투입' 단계로 진입**

- 상용화 경로 구체화: RMAC 학습 → 성능 검증 → HMGMA·현대글로비스 파일럿 → 실제 생산 투입
- 2028년 HMGMA 투입 → 2030년 부품 조립공정 확대 목표

**핵심 경쟁력 = 로봇 성능보다 'Fleet × 가동률 × 데이터'**

- 제조용 로봇의 핵심은 수천 번 안정적으로 반복 작업하는 것
- 향후 평가지표 이동: 로봇 성능 → **실제 배치 대수·가동시간·활용률**
- 신뢰성 ↑ → 가동률 ↑ → 데이터 ↑ → AI 성능 ↑ → 추가 배치 ↑ = **Physical AI Data Flywheel**

**현대차그룹의 Captive 환경 = 오히려 강력한 경쟁우위**

- HMGMA = 제조 데이터 / 현대글로비스 = 물류 데이터
- 한국·미국·중국 로봇훈련 거점 + 글로벌 생산거점
- 학습 → 배치 → 데이터 축적 → 재학습을 빠르게 반복 가능

**수혜주 관점**

- **현대모비스**: Atlas 1대당 바디 액추에이터 31개, 11월 시제품 납품 예정. Atlas 양산 확대 시 액추에이터 물량 증가로 로봇 부품 사업의 사업화 가시성 상승
- **현대글로비스**: 부품 서열(Sequencing)은 반복성·구조화가 높아 초기 상용화에 적합. 실제 파일럿/배치가 확인되면 '현대차 = 제조 + 현대글로비스 = 물류'의 Physical AI 초기 생태계 구축

**결론**: Atlas의 투자 포인트가 '로봇을 얼마나 잘 만드느냐'에서 **'얼마나 많이, 오래, 실제 공장에서 일하게 하느냐'**로 이동. HMGMA·현대글로비스의 실제 배치가 Atlas 상용화의 가장 중요한 검증 이벤트이며, 현대모비스는 로봇 부품 양산 수혜의 핵심 후보.

## 5. 부록 B — AI 인프라 금융과 'Dark GPU' 리스크

**원문 (중국언론, wallstreetcn)**: 「엔비디아 5,000억 달러 AI 금융 계획에 숨은 우려, 트럼프 고문 '다크 GPU' 과잉 위험 경고」

- 트럼프 대통령의 기술 고문 David Sacks는 팟캐스트에서 엔비디아의 5,000억 달러 AI 금융 계획이 직면한 가장 큰 위험은 **연산능력 과잉**이라고 경고
- 이를 인터넷 버블 이후 발생했던 '다크 광섬유(dark fiber)' 위기에 비유. GPU가 대량으로 유휴 상태에 놓이고 가격이 붕괴할 경우 AI 인프라 투자망 전체에 큰 충격
- 동시에 데이터센터 건설에 대한 정치적 반발이 오히려 AI 연산능력 과잉 공급을 막는 역할을 할 수도 있다고 지적
- 출처: https://wallstreetcn.com/articles/3779545

**'Dark GPU'가 정확히 무엇인가**

- 닷컴버블 때 통신업체들이 인터넷 수요를 지나치게 낙관해 광섬유를 대량 설치했고, 버블 붕괴 후 상당 부분이 미사용으로 남은 것을 **Dark Fiber**라 불렀음
- AI에 대입하면: 데이터센터 건설 → GPU 대량 구매 → AI 수요 예상 → 실제 사용률 부족 → 가동되지 않는 GPU = **Dark GPU**
- GPU가 고장 난다는 의미가 아니라 **비싸게 투자했지만 충분히 사용되지 않는 연산능력**을 뜻함. Sacks는 이를 AI 인프라의 가장 큰 잠재적 위험으로 지목

**금융이 붙으면 생기는 양방향 레버리지**

- 정방향: AI 수요 → 투자 → GPU 구매의 속도가 빨라짐
- 역방향(실제 AI 수요가 예상보다 느릴 때): GPU 과잉 → 가동률 하락 → GPU 임대료/가격 하락 → 데이터센터 수익성 악화 → 금융비용 부담 → 투자 축소

**의외의 포인트 — Sacks는 AI 수요 자체를 부정하지 않았다**

- 오히려 현재 상황에서 데이터센터 건설의 **정치적·물리적 장애물이 Dark GPU를 막아주는 역할**을 할 수 있다고 봄
- 즉 **'AI 수요 증가 속도 = 데이터센터 건설 속도'**가 되는 것이 오히려 안전
- 데이터센터는 GPU만 주문한다고 바로 가동할 수 없음: **전력 → 송전망 → 부지 → 인허가 → 냉각 → 데이터센터 → GPU → 네트워크**가 모두 필요
- 그래서 정치적 반발과 인허가 지연이 역설적으로 AI 공급과잉을 방지하는 브레이크가 될 수 있다는 논리

**시장의 위치 정리**

- 결국 모든 게 미래 어느 시점의 최종수요인데, 그걸 정확히 아무도 예측하지 못하니 그나마 AI 모델·데이터센터·GPU 업체 전망에 기대는 것
- 투자는 GO 해야 하는데 자금이 딸릴 것 같으니 서로 묶어서(상호 금융) 가보자는 구도
- 이런 우려(시나리오)와 병목이 말끔히 해소되기 전까지 **양면적 시각은 계속될 것**
