| 축 | 핵심 결론 | 실전 함의 |

| **방산** | 한화시스템 필리지분 매각 = 에어로 미국 방산 플랫폼 **재배치** | 유동성 + 지상·함정 프라임 비전 |

**통합 투자 문장**  
> AI는 “끝나는가”가 아니라 **① CapEx 지속 → ② 공급부족(메모리·기판·CCL·전력) → ③ ASP·마진 유지**가 동시에 성립하는가가 포지션을 가른다. 병목은 GPU에서 **메모리·연결·전력**으로 이동 중이다.

## 1. 교차 테마 인사이트 (13건을 관통하는 증류)

### 1-1. 병목의 이동: Compute → Memory → Interconnect → Power

1. **추론·긴 컨텍스트** → KV Cache·대역폭 → HBM/DRAM (HBM헤게모니, MU Bull/Bear, UBS CapEx)
2. **고속 신호** → Low-loss CCL·HVLP·고다층 PCB·SerDes (PCB/CCL 용어, 소부장 PCB 유니버스)
3. **패키지 기판** → ABF/FCBGA CAPA 선점·선급금 경쟁 (삼성전기·중국 AI칩)
4. **전력** → 비상발전기·On-site 엔진·FDC (조선·Generac–Amazon)

실전: 테마를 “AI 관련주”로 묶지 말고 **어느 병목의 가격결정력**을 사는지 라벨링.

### 1-2. “수요 지속”과 “마진 지속”은 다른 변수

- MU: Bull은 AI계약·SCA·선급금으로 **사이클 PER 재평가** 주장 / Bear는 **GPM 85% 정상화 착시** 경고.
- UBS: 2025→27 AI CapEx 폭증의 **~90%가 메모리 지출(가격) 상승**.
- MLCC/CCL: 물량 + 고사양화가 **동시에** 가는 구조적 사이클 (재고보충 사이클과 구분).

실전 체크리스트:
- [ ] AI CapEx 가이던스 유지?
- [ ] HBM/DRAM/기판/CCL **리드타임·선급금·장기계약** 뉴스?
- [ ] ASP/GPM 코멘트에 “정상화/둔화” 단어 등장?
- [ ] 증설 가동 시점(예: 고사양 MLCC 2027H2) 앞두고 기대 선반영?

### 1-3. Agent·거버넌스는 수요를 줄이지 않는다

- HITL/HMOL = 권한 통제. 사람 승인은 마지막 한 스텝.
- Agent = 긴 Context + RAG + Tool + 다Agent 교환 → **토큰·KV Cache·장기 메모리↑**.
- Safety로 Tool 호출을 제한해도, **호출당 처리량**(문서·임베딩·리랭킹)이 늘면 메모리 수요는 유지될 수 있음.
- 산업 전체: Agent 1개당 사용량 < **사용자·기업 수 증가**.

### 1-4. Open Model ≠ 바로 인프라 수혜 확정

- Vercel: Open 토큰 78.4% / Spend는 여전히 Closed(Anthropic 등) 비중 큼.
- 다음 단계 신호: **Open Spend Share**가 따라 올라오는가.
- 연결고리: 중국 Open-weight → 추론단가↓ → 사용량↑ → DC·전력·메모리.

### 1-5. 매크로는 역풍, 섹터는 이익 기대가 지탱

- 9/18: 10Y 5% 재돌파에도 NASDAQ +, SOX +2.78%.
- 공식 깨짐: “금리 5% = 기술주 매도”.
- 다만 유가 $100 + 추가인상 가능성은 **밸류 부담 재확대** 리스크.
- 운용: 단기는 변동성 관리, 중장기는 AI 실적 축으로 비중 유지 여부 판단.

## 2. 문서별 상세 증류 (원문 핵심 보존)

### A. 마이크론 BULL VS BEAR

**현재 숫자 (원문)**  
- Q3 FY26 매출 $41.5B / GPM 84.9%  
- Q4 가이던스: 매출 ~$50B, GPM 86%, EPS ~$31  
- 데이터센터 매출 $25.3B (61%)  
- SCA 최소 매출 ~$100B  
- 고객 선급금·금융약정 ~$22B  

**Bull**  
AI 수요·계약·HBM 구조면 **과거 메모리 사이클 PER 적용은 부당**.

**Bear**  
GPM 85~86%를 “정상”으로 가정하는 것이 더 위험. ASP 상승률만 둔화해도 EPS 증가율 급락.

**필수 3단계 프레임**

| 단계 | 내용 | 충족 시 |
|---|---|---|
| ① | AI CapEx 지속 | 매출 성장 가능 |
| ①+② | HBM/DRAM 공급부족 지속 | 높은 메모리 가격 지속 |
| ①+②+③ | ASP·GPM 고수준 유지 | 낮은 PER 재평가 가능 |

**반대 시나리오:** AI 수요는 남는데 ②→③ 약화 → 매출↑ + EPS 증가율↓ + GPM 정상화 동시 출현.

**가르는 질문 (원문 그대로 핵심)**  
> “AI가 끝나는가?”가 아니다.  
> “AI는 계속 성장하더라도, MU의 85% GPM과 초고속 ASP 상승이 **얼마나 오래** 지속되는가?”

**시나리오 맵**  
- Bull: CapEx → HBM4/4E → DRAM 부족 → ASP 강세 → 고이익 구조화 + Multiple 재평가  
- Bear: CapEx 지속해도 공급완화 → ASP 둔화 → GPM↓ → EPS 정상화 → PER 착시  

**실전 활용**  
- 모니터링 지표: HBM 계약·선급금·SCA 업데이트, ASP QoQ, GPM 가이던스 wording, 경쟁사 증설 가동.  
- 포지션: “AI 테마”가 아니라 **마진 지속기간에 베팅**하는지 명시.

### B. 삼성전기 관련 — 중국발 FCBGA 부족 · MLCC 전망

#### B-1. FCBGA / 패키지 기판

- ByteDance: 2030년까지 연간 **1,000억위안(약 149억 달러)** 규모 패키지 기판 구매 준비.
- Huawei HiSilicon, Hygon, ByteDance, OSAT의 CAPA 확보 경쟁 심화. 기존 증설만으로 신규 수요 대응 어려움.
- 고사양 CAPA 상당 부분 **Nvidia 등 장기계약 선점** → 후발은 대규모 물량 보장 없으면 우선배정 곤란.
- 일부 기판사: CAPA의 최대 **50% 선급금 또는 공동 증설** 요구.
- 중국 AI칩 업체 → 대만계 기판의 **중국 현지 CAPA** 확보에 적극 (Qunce/Unimicron, Nan Ya PCB Kunshan, Leading Interconnect/Zhen Ding 등).
- 중국 PCB의 FCBGA 진입 확대하나, 대만 대비 **기술격차 3~5년** 평가.
- Shennan Circuits: 상반기 패키지 기판 매출 36.7억위안(+110.8% YoY), GPM 31.35%(+16.2%p). BT 기판·고사양 FCBGA 양산 확대.
- **결론 문장:** 중국 AI 칩 수요가 글로벌 고사양 패키지기판(특히 ABF 기반 FCBGA) 공급부족을 **추가로 심화**.

**인과 체인**  
중국 AI ASIC 확대 → 고사양 FCBGA 수요↑ → Nvidia 등 선점 → 신규 고객 선급금·공동증설 → 공급부족·가격협상력↑.

#### B-2. MLCC (중국 고사양)

- 일부 중국 업체 AI용 고사양 MLCC 주문이 **2027년 2Q까지** 확보.
- 발주 시점: 1~2개월 전 → **3~6개월 전**으로 선행화.
- 수요처: AI 서버 + AI Workstation + 800G/1.6T 광모듈.
- Workstation: Mini PC 대비 MLCC 탑재 **2~3배**, 고용량 수요 약 **2배**.
- 광모듈 MLCC: 800G ~200개 / 1.6T **500~1,000개** / 3.2T **1,200개+** → 1.6T는 800G 대비 **2.5~5배**.
- Fenghua: 고사양 MLCC 비중 35~40%, 높은 가동률.
- 증설: AI서버·전장 고용량 중심. 신규 CAPA 풀가동 시 일부 업체 월 **~800억개**.
- 수급: 고사양 부족 **2026 4Q ~ 2027 상반기** 지속 → **2027 하반기** 이후 완화 가능.
- 사이클 특징: 스마트폰/PC 재고사이클 ≠ 이번. **탑재량↑ + 고사양화** 동시.

**투자 포인트**  
광모듈 속도 세대교체 = 광부품 ASP만이 아니라 **모듈당 RF MLCC 탑재량 구조적 증가**.

**실전 (삼성전기 관점)**  
- FCBGA: 글로벌 타이트 + 중국 추가 수요 = 협상력·ASP 지지 논리.  
- MLCC: 고사양·서버·광모듈 믹스. 완화 시점은 2027H2 — 그 전 과열 밸류 경계.  
- 경쟁: 중국 증설 속도와 품질 격차(3~5년)를 동시에 추적.

### C. AI 거버넌스 · HML · HMOL · 메모리

**프레임 전환**  
“개발 멈출 것인가” → “얼마나 빠르게 개발하면서 **어느 수준 안전장치**를 동시에 쌓을 것인가”.  
미·중 경쟁 → 속도전 → Agent 통제 위험 → Human Control/Guardrail → **거버넌스 경쟁**.

- 9/20 미·중 고위급: AI safety·guardrails 의제 (Reuters).
- 투자 관점: AI Safety = 성장의 반대말 ❌ → 장기 성장을 위한 **운영 인프라** 가능.
- Microsoft: 중국 경쟁 vs Safety를 양자택일로 보지 않음 → 거버넌스가 경쟁 **속에서** 구축.

**HITL vs HMOL**  
- HITL: 중요 행동은 사람 최종 승인 (예: 항공권 후보 3개 → 승인 → 결제).  
- 리스크 3단: Low(자율) / Medium(실행 후 확인) / High(승인 필수: 송금·계약·거래·보안 등).  
- Agent가 검색→분석→보고서→이메일→발송까지 하면, 단계마다 승인하면 Agent 이점 소멸 → 미래 핵심은 **HMOL / Human-on-the-Loop**(대부분 자율, 위험 순간에만 개입).

**메모리 수요 논리**  
자율성↑ → 행동 권한↑ → 피해 가능↑ → Permission·Monitoring·Human Control → 안전한 상용화.  
핵심 질문: “얼마나 똑똑한가” → “**어디까지 권한을 줄 것인가**”.

- HITL ≠ GPU 감소. 승인 전 추론은 그대로. Agent는 챗봇보다 Context·기록·RAG·Tool·다Agent 교환·반복 추론 필요 → 토큰↑.
- Training → Inference로 메모리 수요 중심 이동 촉진.
- 권한 통제가 **새 메모리 수요**를 만들 수 있음: 이메일·고객·규정·프로젝트·의사결정·선호·이전 Agent 결과 = **장기 Agent Memory**.
- Compute → Memory → Storage 전 계층 중요.
- 예외: Safety로 Tool 100회→20회 제한 시 해당 Agent workload↓ 가능. 그러나 **호출 횟수 < 호출당 처리량**(긴 Context·문서·Embedding·Reranking·KV Cache).
- 결정 변수: RAG 횟수보다 **KV Cache + Context + 장기 Agent Memory**.
- 산업: Agent당 사용량↓보다 **기업·사용자 수↑**가 훨씬 중요.

**실전**  
거버넌스 뉴스를 CapEx 감속 신호로 단정하지 말 것. Agent 엔터프라이즈 침투 = 메모리·스토리지·Inference 장기 테마 강화로 해석하는 편이 원문 논리와 정합.

### D. AI 속도조절론 vs 반독점 · AI Force · 엘크의 뿔

#### D-1. 반독점 변수
- 본질: 안전 협력 자체보다, 경쟁사 간 **개발 속도 조율 = 담합?** 쟁점.
- AI Pacing → Antitrust 리스크 → CapEx·GPU/DC 투자 속도에 **규제 변수**.
- 단, **원고 주장 단계**. 실제 감속·CapEx 둔화 확인된 바 없음.

#### D-2. AI Force
- 트럼프: AI Force 창설, AI를 **GDP 25%급** 산업으로 육성 발언.
- 감속론 부상 속 정부는 **억제보다 주도권 확보**.
- 함의: GPU→HBM→첨단패키징→DC→전력/변압기 투자 지속성에 **긍정적 신호**.
- 주의: GDP 25%는 공식 전망 아님. 조직·권한·예산 미공개.

#### D-3. AI 성장 키워드 3가지
1. **소의 뿔(누적) vs 엘크 녹각(반복 재투자)**  
   - 소(horn): 사용량·데이터·모델 **평생 누적**.  
   - 엘크(antler): GPU·HBM·네트워크·DC **세대교체마다 통째로 재투자**.  
   - 초기 폭발 → 이후 성장률 정상화(Peak 아님) → 경쟁 생존 위해 차세대 투자 반복 = **Duration Extension**.
2. **지출폭포 (Expenditure Cascade)** — 프론티어 무한경쟁 소용돌이.
3. **헬멧은 싫지만 규칙에는 찬성** — 속도조절론의 모순.

**엘크 비유 확장**  
- 성장·경쟁·비용/위험·방어(가드레일)·반복(세대마다 안전장치 업그레이드).  
- 차별점: Blackwell→Rubin으로 가도 기존 GPU **전부 폐기 아님** (추론·저사양·기업용 재배치).  
- 천적(병목): 정면력보다 **약한 고리** — GPU·HBM·네트·전력·DC 생태계에서 **병목 선점**.  
- 최근: 속도조절·규제가 “상대적으로 경시되던 천적 변수”로 부상 → 복잡도↑.  
- 목적: 큰 뿔(Capability) 자체가 아니라 **인간 효용 전환**.  
- 모델사 공감대(원문): 프론티어 숨고르기 핑계/안전망 보강 후 **Agentic·추론 시장** 집중.  
- 핵심 과제: Agentic 추론 폭발 + **피지컬 AI로의 캐즘 없는 이행**. 지표 후보: 토큰 지속 고성장.

**실전**  
규제 헤드라인에 일희일비하지 말고, (1) 실제 CapEx 가이던스 (2) 병목 장악 기업 (3) Agentic/추론 지표를 우선.

### E. HBM 헤게모니

**출발 신호 (GPT-6 ASTRA, 9/3)**  
- Context 1.05M 토큰 / Fast 모드: 2배 속도·2배 가격 / 272K 초과 프롬프트 별도 요금.  
- 디코더는 토큰마다 가중치·KV Cache 전체 재독 → 긴 Context = **토큰당 대역폭↑**.  
- 요금 구조 → 원가에 **메모리가 큼**을 시사 (가격정책 추론이지 OpenAI 공식 원가 공개 아님).

**OpenAI ASIC Jalapeño**  
- 성과지표에서 칩당 처리량 제외 → **대기시간·요청당 에너지**만.  
- 대기시간 = 디코드 속도 = **대역폭**.  
- HBM4: **216GB / 15.4TB/s** (최근 ASIC 중 유일하게 HBM4 탑재 언급).

**기초식**  
`대역폭(GB/s) = Stack수 × I/O핀수 × 핀당속도(Gb/s) / 8`

**전력 벽**  
대역폭↑ → 데이터이동↑ → **I/O 전력↑** → 핀속도만으로는 한계.

**해결 방향**  
1. **커스텀 HBM:** 베이스다이를 로직공정으로 축소, XPU 면적 5~10%인 메모리 컨트롤러를 베이스다이로 이전.  
2. **NVIDIA NVHBM:** HBM4 대비 대역폭 +30%, 전력 −15%.  
3. **zHBM:** DRAM을 XPU 위(수직) — 2.5D 수평 I/O 제거. HBM5 대비 I/O 전력 −70%, 대역폭 2.5배+ 목표, 절감 100W를 GPU 연산에 환류.

**결론 (가장 중요)**  
> 경쟁이 “HBM을 얼마나 많이 생산하느냐” → “얼마나 **빠르고 전력효율적으로 XPU와 연결**하느냐”.  
> DRAM 다이뿐 아니라 **베이스다이 로직·첨단공정·TSV·하이브리드 본딩** 후공정 중요성↑.  
> HBM5로 갈수록 “메모리만 만드는 회사” → “**로직+패키징**까지 잘하는 회사”.

**실전**  
삼성·SK하이닉스·마이크론 비교 시 출하량만 보지 말고 **커스텀 HBM·베이스다이·본딩** 로드맵·고객 공동설계 뉴스 가중.

**중국 모델**  
DeepSeek / GLM / Qwen / Kimi → Open-weight → 저렴한 추론 → Gateway 토큰 급증 → Inference Cloud 기회.

**분기점**  
Open Token Share 78%가 **Open Spend Share**로 이어지면 “사용량”에서 “**inference economics 재편**”으로 단계 상승.  
인프라 관점: Token Share(얼마나 일하나)가 Spend보다 **더 중요할 수 있음**.

**연결고리**  
중국 경쟁우위 → 추론비용↓ → 사용량↑ → **DC·전력·메모리**.

**DC 평가 축**  
면적 ❌ → **전력·GPU 밀도** → GPU utilization × 전력 × 네트워크 × 냉각.

**유리한 곳**  
① AI GPU Cloud (Nebius/IREN/CoreWeave)  
② Inference Platform (Together/Fireworks/Baseten)  
③ 전력 (발전·BTM·변압기·송전)  
④ 반도체 (NVDA/AMD → HBM → DRAM → SSD)

**Vercel Gateway란**  
여러 모델 API를 한 인터페이스로 연결하는 허브.

**Chamath 평가**  
예측가보다 **테마를 일찍 잡는 투자자**. Groq(2016), Social Capital Open vs Closed 99p 보고서(2026-09-18), 8090 Software Factory 창업·CEO.

**실전**  
국내 투자: 해외 Inference Cloud 직접매수뿐 아니라, Open 확산 → **국내 메모리·전력·DC 관련** 수요 논리로 번역. Spend share 대시보드를 월간 체크.

### L. 메모리 가격 결정적 비중 · 휴머노이드 로봇

#### L-1. UBS AI CapEx
| 연도 | AI CapEx | 메모리 지출 | 메모리 비중 |
|---|---|---|---|
| 2025 | $5,060억 | $710억 | 14% |
| 2026 | $9,980억 | $3,670억 | 37% |
| 2027 | $1조4,470억 | $9,230억 | **64%** |

- 비메모리 AI 지출: 2026 ~$6,310억 → 2027 **$5,250억으로 감소**.  
- 2026 증가분의 ~**60%**가 메모리 가격.  
- 2025~27 전체 증가분(~$1조)의 ~**90%**가 메모리 지출 상승.  
- 거시: 미국 실질 GDP 견인 제한적 / **아시아 메모리 생산국으로 이익 이전**.

**실전**  
“AI CapEx 2배”를 GPU 대수 2배로 읽지 말 것. **가격(메모리) 효과**가 주인공. 아시아 메모리·소부장 상대 매력 논리 강화.

#### L-2. 휴머노이드 3대 논쟁 (바클레이즈)
1. **대규모 보급:** 시장 예상 2030보다 늦은 **2035 전후** 가능. 병목은 하드웨어보다 **인지·추론·행동 AI**. 규모경제(비용↓)와 지능(가치입증)을 동시에 풀기 어려움.
2. **연산 수요:** DC(시뮬·합성데이터·학습) vs 엣지(실시간 추론 — 지연·전력·안전). DC 추가수요는 제한적, **엣지 AI** 수혜 가능. 단 보급 전에도 시뮬·학습으로 DC 수요 **선행**.
3. **꼭 인간형?** Physical AI 첫 대규모 확산이 휴머노이드일 필요 ❌. 협동로봇·AMR·드론·사족 등 이미 활용. 아마존 로봇 100만+대도 비인간형. 인간형은 기존 환경·다목적 장점 / 명확 작업은 전용 폼팩터가 효율적.

#### L-3. 유니트리 왕싱싱
- 최대 단점: **얼라인먼트** (모델 I/O ↔ 실제 로봇).  
- “마지막 몇 cm·mm” 오차가 범용·가정 보급 가로막음.  
- 폭발 조건: 초면 가정에서 “방 정리해” 한 마디에 **사전학습 없이** 수행.

**실전**  
휴머노이드 테마 단기 과열 경계. Physical AI는 **전용 로봇·엣지·시뮬** 경로가 먼저일 수 있음. D문서의 “캐즘 없는 이행”과 연결.

### 3-4. 소부장 매매 룰카드 (원문 규칙화)

1. 삼전닉스 5%+ 광란일이면 개별 소부장 신규 비중↑ 자제.  
2. 커버 2사+ / 3개월 리듬 없는 종목은 테마성으로만.  
3. 목표가 대비: <60% 공격 / 60~80% 본게임 / >80~90% 축소.  
4. PER30+ = 성장50%+ 또는 고객 확대 증빙 없으면 패스.  
5. HBM 고학습 구간 → PCB/SoCAMM/ CCL로 **정보 비대칭** 노리기.  
6. 하향리포트 러시 후 1~2개월 + **두 번째** 긍정 리포트 = 하이리스크 진입 윈도우.

## 6. 클로징 — 실전에서 외울 문장 5개

1. **가르는 질문:** AI 종료 여부가 아니라 **고마진·고ASP의 지속기간**.

5. **DC:** GPU 산업이 아니라 **전력 확보 산업** (육상 발전기 → On-site → FDC).
