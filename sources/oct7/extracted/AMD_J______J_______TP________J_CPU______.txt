5. 왜 Agent가 CPU를 훨씬 많이 필요로 하나? 
기존 ChatGPT형 구조를 단순화하면: 
사용자 질문 
→ CPU가 요청 관리 
→ GPU가 LLM 추론 
→ 답변 
그래서 AMD가 설명했던 기존 구조는 대략 
CPU 1 : GPU 4~8이었습니다.  그런데 Agent는 다릅니다. 
예를 들어 AI에게 
“이번 주 삼성전자 실적을 분석하고 투자 의견을 만들어줘.” 라
고 하면 Agent가 
① 웹 검색 
② 자료 수집 
③ PDF 읽기 
④ DB 조회 
⑤ 코드 실행 
⑥ 계산 
⑦ 다른 AI 모델 호출 
⑧ 결과 검증 
⑨ 다시 검색 
⑩ 최종 보고서 작성 
을 반복합니다.

즉 GPU가 LLM 계산을 담당하는 동안 CPU는 
Orchestration(작업 조율) 
Tool call(외부 도구 호출) 
Database 처리 
Security 
API 처리 
Memory/Storage I/O 
를 담당합니다. 
AMD도 Agentic AI에서는 기존 1 CPU : 4~8 GPU에서 1 CPU : 1 
GPU 또는 경우에 따라 CPU가 더 많은 구조로 이동할 수 있다고 
설명합니다.
