# 탐색적 세 변수 가설 — 정수 점수는 잠그지 않음

임상 도구가 아닙니다. 점수 이름을 유지할지, 가중치를 어디서 다시 뽑을지는 **원자료 재적합 이후**에만 결정합니다.

유지하는 문장:

> Non-STEMI OHCA에서 단발 효소는 culprit 감별에 기여하지 않는다. 나이와 초기 리듬이 더 중요하다. 병변 사전확률이 높아져도 즉시 조영술의 예후 이득은 이 자료가 증명하지 않는다.

---

## 3–2–1은 최종 배점이 아님

나이 3, 리듬 2, 성별 1은 **CK-MB가 들어 있는 4변수** 표준화 β(1.01 / 0.53 / 0.32)를 0.32로 나눈 잔여입니다. CK-MB를 빼면 세 계수가 달라집니다. 지금은 없는 변수의 분모로 남은 변수를 스케일한 상태입니다.

원자료가 오면:

1. Non-STEMI에서 **Age(연속) + shockable + sex만** 다시 적합한다.
2. 그때의 β로 정수를 다시 매긴다. 성별 계수가 작으면 1점이 사라질 수 있다.
3. 59세 이분법은 민감도 분석이다. 1차 보고는 연속 나이.
4. Bootstrap 보정 AUC가 0.70을 넘을 때만 점수화를 남긴다. 아니면 다변량 표로 끝낸다.
5. 본문 제한 네 줄: 탐색적, 단일기관, 외부 검증 없음, CAG 적응 지침 아님.

---

## 0.808을 Door 성능으로 쓰지 말 것

2026 재분석의 중첩 AUC는 **CK-MB Δ를 바닥에 두고** 나이·성별·리듬을 더한 값입니다.

| 중첩 | Non-STEMI AUC |
|---|---:|
| CK-MB Δ 단독 | 0.552 |
| + 나이 | 0.766 |
| + 성별 | 0.808 |
| + shockable | 0.832 |

0.808은 CK-MB Δ + 나이 + 성별입니다. Age + rhythm + sex가 아닙니다. 3변수(효소 없음)의 겉보기 AUC는 아직 없습니다. 본문에 0.808을 고정 성능으로 쓰지 않습니다.

---

## 점수화가 필요 없을 수 있음

검증 결과가 ‘나이와 shockable만 유의하고 성별은 약하다’이면 이름 붙인 점수 대신 다변량 표 하나로 끝내는 것이 더 정직합니다.

STEMI 제외, 초기 트로포닌 제외, CK-MB 1점 없음, 층 없음, CAG 결정 문장 없음 — 이 방향만 유지합니다. 예전 이름 ACES와 포켓 카드는 폐기 상태입니다.

산술 HTML의 3–2–1은 잔여 가중치를 보여 주는 확인용입니다. 잠정치가 아닙니다.
