# OHCA-ARS — 탐색적 정수 초안 (임상 점수 아님)

**Age · Rhythm · Sex.** 0–6점. Non-STEMI ROSC 전용.

이전 이름 ACES는 폐기합니다. CODE ACES 2(CPR 질 관리), 캐나다 ACES(증후군 감시)와 겹칩니다.  
CK-MB 1점은 1차 점수에서 뺍니다. 21.4 ng/mL은 STEMI가 들어 있는 107명의 Youden이고, Non-STEMI에서 CK-MB Δ는 AUC 0.552, p=0.621이며 Δ가 있는 환자는 63명 중 35명뿐입니다.

이 문서는 침상 카드가 아닙니다. 미검증 로지스틱 모형을 Framingham/Sullivan 방식으로 정수화한 **연구 초안**입니다. Low/Intermediate/High 층은 쓰지 않습니다. 계산기를 배포하거나 치료에 묶지 않습니다.

유지하는 방향만 네 가지입니다. STEMI 제외, 초기 트로포닌 제외, 나이 가중, 효소 비대기.

---

## 논문에 쓸 문장

다변량 스코어링으로 CAG를 결정한다는 문장은 쓰지 않습니다.

> Non-STEMI OHCA에서 단발 효소는 원인 감별에 필요 없다. 나이와 초기 리듬이 더 중요하다.  
> 정수 점수는 탐색적이며, 외부 검증 전과 CAG 적응 지침이 아니다.  
> High층이 사실상 ‘59세 이상 + shockable’이라면 새 정보의 추가분은 작다.

COACT·TOMAHAWK·TARGET-CTCA와 같이, 병변 사전확률이 높아져도 즉시 조영술이 사건을 줄인다고 이 점수가 증명하지 않습니다. Low에 해당하는 진술(“트로포닌만으로 CAG를 밀지 않는다”)만 데이터가 받칩니다.

---

## 1차 점수 (Door, 0–6)

보고된 표준화 β를 성별 계수 0.32로 나누고 반올림했습니다. 방법은 표준입니다. 문제는 계수와 컷오프가 나온 표본입니다.

| 항목 | 기준 | 점 | β / 0.32 |
|---|---|---:|---|
| Age | ≥ 59세 (Non-STEMI Youden) | 3 | 1.01 → 3.16 |
| Rhythm | 초기 VF / pVT | 2 | 0.53 → 1.66 |
| Sex | 남성 | 1 | 0.32 → 1 |
| 합 | | **0–6** | |

단위: 나이는 세. CK-MB를 다시 넣을 일이 있으면 논문 시약대로 **ng/mL**. cTnI는 **pg/mL**이며 점수에 넣지 않습니다.

0.808은 나이+성별+리듬 **연속 로지스틱**의 학습 표본 겉보기 AUC입니다. 정수 0–6의 AUC가 아닙니다. 사건 30건에 변수 3–4개이고 bootstrap optimism이 없습니다. 이 규모에서 0.83은 흔히 0.70 아래로 내려갑니다. 그때는 점수화 자체를 접습니다.

---

## 1차에서 뺀 것

| 항목 | 이유 |
|---|---|
| 초기 cTnI | Non-STEMI AUC 0.548, p=0.518 |
| CK-MB Δ 1점 | 대상 군에서 NS. 컷오프는 전체 107명 것. 결측 28/63 |
| 0–2 / 3–4 / 5–7 층 | 한 명도 채점되지 않음. 직관적 경계 |
| 치료 문장 (Low→CAG 보류, High→CAG 논의) | 층이 없고, 조영 이득도 이 데이터가 없음 |
| 포켓 카드 | 임상 올리기 이름 |

나이 3 + shockable 2 = 5가 예전 High의 거의 전부였습니다. 많은 센터의 Non-STE OHCA 휴리스틱과 같습니다.

---

## 원자료가 오면 이 순서만

1. Non-STEMI 63명에게 Door 0–6만 다시 채점한다. Full(효소)은 결측 분석 뒤.
2. 각 점수의 culprit 비율, ROC, Youden, (그때 가서야) 우도비를 낸다. 층 경계는 그 숫자로 고친다. 지금은 층을 만들지 않는다.
3. Bootstrap으로 보정 AUC와 optimism을 본다. 0.83이 0.70 아래로 가면 점수화를 접는다.
4. CK-MB 1점은 Non-STEMI에서 유의하지 않으면 영구 제거한다. 지금 가정은 제거 쪽이다.
5. 본문 제한: “탐색적 점수, 외부 검증 전, CAG 적응 지침 아님.”

예시 네 개는 산술 확인용입니다. 66세 남성 VF가 5점인 것은 3+2이지, 그 환자의 culprit 확률이 아닙니다.

계산기 HTML은 같은 산술을 보여 주는 연구용 페이지입니다. 층을 붙이지 않으며 임상 사용 금지입니다.
