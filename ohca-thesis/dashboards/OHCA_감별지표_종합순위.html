OHCA에서 Cardiac vs Non-cardiac Origin 감별 지표 종합 순위

33개 변수 · 단변량 + 다변량 분석 · 전체(N=107) + Non-STEMI 하위군(N=63) · Mann-Whitney U / Chi-square / ROC / Logistic Regression

결론 1: 다변량 모델이 최우수 — AUC 0.832 (Non-STEMI에서도)

CK-MB 변화량 + 나이 + 성별 + Shockable rhythm 조합 시 Non-STEMI에서도 AUC 0.832, 민감도 84.6%, 특이도 72.7%

회귀계수: 나이(β=1.01) > Shockable(β=0.53) > CKMB변화량(β=0.40) > 성별(β=0.32)

결론 2: Non-STEMI에서 유일한 단독 유의 변수는 "나이"

Non-STEMI 63명에서 나이만 유일하게 유의: AUC 0.693, p=0.009 (Cardiac 중앙값 66세 vs Non-cardiac 56세)

바이오마커(cTnI, CK-MB)는 Non-STEMI에서 전부 유의하지 않음

결론 3: cTnI는 어떤 형태로든 감별력 없음

첫째 cTnI (AUC 0.572, NS) / cTnI 변화량 (AUC 0.530, NS) / Non-STEMI에서 둘째 cTnI AUC 0.478 (방향 역전)

6. 논문 활용 최종 요약

Negative Finding (단변량)

🔴 cTnI: 어떤 형태(첫째/둘째/변화량)로든 Non-STEMI에서 감별 불가

🔴 CK-MB: 전체에서 유의(AUC 0.737)하지만 Non-STEMI에서 붕괴(0.552)

🔴 CPR시간, 제세동에너지/횟수: 전부 유의하지 않음

🔴 기저질환(HTN, DM, CAOD): 전부 유의하지 않음

🟡 나이만 유일하게 유의 (p=0.009, AUC 0.693)

Positive Finding (다변량)

🟢 나이 + CK-MB변화량 + 성별 + Shockable 조합 시

→ Non-STEMI에서도 AUC 0.832

→ 민감도 84.6%, 특이도 72.7%
