# 한 장 요약

## 숫자 세 개

1. **운영 손익분기 9.17억/월** — 이 밑에서는 부부 월급은 나오지만 원금은 1원도 안 줄어든다.
2. **7년 완제선 11.36억/월, 6년 완제선 11.83억/월** (무이자 가정).
3. **7년 내 소유권 확보 확률 8%, 10년 내 11%**.

## 도달 가능 vs 유지 가능

- 10년 완제(10.51억/월): 단년도 달성확률 31% → 그 기간 평균 유지확률 20% → 실제 완제확률 11%
- 7년 완제(11.36억/월): 단년도 달성확률 22% → 그 기간 평균 유지확률 15% → 실제 완제확률 8%
- 6년 완제(11.83억/월): 단년도 달성확률 18% → 그 기간 평균 유지확률 12% → 실제 완제확률 7%
- 월 2일 휴무가 10년간 유지될 확률 13%, 중앙 2.8년에서 깨진다

## 부부가 실제로 손에 쥐는 돈

- 1~5년 부부 합산 세후 월수령 중앙값 **4,003만** (p10 2,088만 / p90 6,269만)
- 1인 환산 중앙값 **1,766만**, 시간당 7.0만원
- 응급의학 잔류(D-N-Off×4)는 시간당 24.2만원 → 딜은 그 **0.29배**

## 결정적 조항 (계약서에서 확인되면 분산이 접힌다)

- **계약에 이자 6% (총 지불 113억 상당)** → 7년 완제 6%, 10년 완제 8%, 부부 세후월 3,998만
- **'매출 90%'가 아니라 '정산이익의 90%'인 경우** → 7년 완제 22%, 10년 완제 25%, 부부 세후월 326만
- **운영 적자를 명의자(부부)가 메우는 구조** → 7년 완제 8%, 10년 완제 10%, 부부 세후월 2,026만
- **적자달의 손실이 원금에 얹히는 구조** → 7년 완제 7%, 10년 완제 10%, 부부 세후월 3,998만
- **최악 조합: 이자 6% + 적자 원금가산 + 연대보증** → 7년 완제 6%, 10년 완제 7%, 부부 세후월 3,998만
- **최선 조합: 무이자 캡 + 연대보증 없음 + 창업자 잔류 의무** → 7년 완제 9%, 10년 완제 12%, 부부 세후월 4,127만

## 결과를 가장 크게 흔드는 변수 5

- 객단가 (12.0 → 16.5): 7년 완제확률 2% → 21% (스윙 18%p)
- 월 환자수(수요) (5200.0 → 7900.0): 7년 완제확률 2% → 19% (스윙 17%p)
- 재료비율 (0.17 → 0.26): 7년 완제확률 14% → 3% (스윙 11%p)
- 직원 수 (40 → 58): 7년 완제확률 14% → 5% (스윙 9%p)
- 부부 선취율 (0.06 → 0.12): 7년 완제확률 14% → 6% (스윙 8%p)

## 이 딜이 '반반'이 되려면 (단독 레버 역산)

- 월 환자수: 탐색 범위 안에서는 단독으로 50%에 도달하지 못함
- 객단가: 14 → **20.50 만원** (×1.46)
- 직원 수: 탐색 범위 안에서는 단독으로 50%에 도달하지 못함
- 부부 선취율: 탐색 범위 안에서는 단독으로 50%에 도달하지 못함
- 시술실 수: 탐색 범위 안에서는 단독으로 50%에 도달하지 못함
- (조합) 실측 매출이 연 150억대인 경우 (수요 9,800명/월 + 객단가 16만) → 7년 완제 **59%**, 부부 세후월 7,199만
- (조합) 연 150억대 + 부부 선취 7% 재협상 → 7년 완제 **69%**, 부부 세후월 7,179만

## 판정

- P(딜 10년 PV > 부부가 그냥 미용 봉직의로 일했을 때) = **26%**
- P(딜 10년 PV > 부부 둘 다 EM급으로 일했을 때) = 11%
- P(딜 10년 PV < 0, 투입 10억도 못 건짐) = **17%**
