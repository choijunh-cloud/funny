# 마켓 노트 정리

Quick 코멘트로 남긴 시장 메모를 하루 단위 문서로 정리해 두는 저장소입니다.

## 구성

```
notes/    정리된 노트(마크다운) + 배포용 워드 파일
tools/    마크다운 → 워드(.docx) 변환 스크립트
```

- `notes/YYYY-MM-DD-<주제>.md` — 원본 정리본. 편집은 항상 이 파일에서 합니다.
- `notes/<한글 제목>.docx` — 마크다운에서 생성한 배포용 워드 파일.

## 워드 파일 다시 만들기

```bash
pip install python-docx
python3 tools/md_to_docx.py notes/2026-08-18-non-samjeonnix.md "notes/8월 18일 NON-삼전닉스 (소부장, SK, 자동차).docx"
```

변환기는 노트에서 쓰는 문법(제목, 글머리표, 번호 목록, 표, 인용, 코드 블록, `**굵게**` / `*기울임*` / `` `코드` ``)을 지원하고, 한글 폰트는 맑은 고딕으로 지정합니다.

## 노트 작성 원칙

- 리포트·기사에서 인용한 수치는 원문 그대로 적고, 자체 가정으로 계산한 값은 '시나리오'로 구분해 표기합니다.
- 원문끼리 어긋나는 숫자는 임의로 고치지 않고 문서 마지막 '숫자 확인 포인트'에 모아 둡니다.
- 각 종목은 `실적 → 논쟁의 핵심 → 다음 확인 포인트` 순서로 정리합니다.
