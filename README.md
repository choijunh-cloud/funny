# 대형 미용의원 현금흐름 모델

톤즈 부평점의 실제 장부나 계약서가 없는 상태에서, 물리적 진료량과 비용을
분리해 추정하는 재현 가능한 Monte Carlo 모델입니다.

## 실행

```bash
python3 clinic_model.py --report estimate.md --json estimate.json
python3 -m unittest -v
```

외부 패키지는 필요하지 않습니다. 기본값은 고정 seed로 20만 회를 실행합니다.

## 핵심 식

```text
월매출 = 월 의사근무일 × 의사근무일당 환자 × 실현 객단가
연 고정비 = 봉직의 원가 + 직원 50명 원가 + 임대관리비 + 기타 고정비
연 상환재원 = 연매출 × (1 - 부부 선취 10% - 변동비율) - 연 고정비
운영 BEP = 연 고정비 ÷ (1 - 부부 선취율 - 변동비율)
세전 완제기간 = 90억 ÷ 양(+)의 연 상환재원
보수적 세후 완제기간 = 90억 ÷ (연 상환재원 - 2026 법인세·지방세)
```

광고·카드수수료·재료비는 변동비에만, 급여·임대료는 고정비에만 넣어 중복을
막았습니다. 총 의사 수는 부부 2명을 포함하며 봉직의 급여는 나머지 인원에만
적용합니다.

## 공개자료와 모델의 경계

- 국세청 TASIS의 2022년 피부·비뇨기과 개인사업자 평균 연매출은
  11억 2,834만원입니다. 대형 미용의원의 직접 peer가 아니므로 모델 보정값이
  아니라 외부 비교 하한으로만 사용해야 합니다.
- 메디게이트 개원입지 서비스는 나이스지니데이타 카드추정 매출을 사용하지만,
  부평5동 상세 수치는 공개 검색으로 재현되지 않았습니다. 따라서 대화에 나온
  2.98억·6.82억을 코드에 넣지 않았습니다.
- 대한의사협회 의료정책연구원 2023년 조사 보도에 따르면 의사는 평균 연
  292.8일 근무, 72.3일 휴무이며 개원의 평균 휴무는 64.8일입니다. 매월
  2일만 쉬면 연 휴무 24일로 매우 강한 일정이지만, 조사 원자료의 분산과
  동일 조건 대조군이 없어 지속 가능성의 p-value를 계산할 수는 없습니다.

가정하지 않습니다.

## 반드시 실제 자료로 교체할 입력

1. 최근 24개월 월별 매출(패키지는 결제액과 시술 이행액 분리)
2. 일별 초진·재진·시술 건수와 환불률
3. 의사별 실제 근무일, 환자 수, 급여의 세전/세후 및 고용 형태
4. 직원 50명의 급여대장, 4대보험 사업주 부담, 퇴직충당금
5. 임대차계약서, 관리비, 장비 리스와 유지보수
6. 재료 매입, 광고, 카드수수료, 부가세
7. 10%의 법적 성격과 90억 상환 종료·이자·보증 조항

이 자료가 없으면 결과는 정밀한 계산일 수는 있어도 정밀한 예측은 아닙니다.
