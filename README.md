# 톤즈 부평점 인수 딜 정밀 추정 모델

검증식(부부 10% 선취, 변동비 30%, 직원 50명 반영 고정비 연 70억, 90억 매출연동 상환)을
코드로 옮긴 결정론 모델 + 50,000경로 몬테카를로 시뮬레이션.

## 실행

```bash
pip install -r requirements.txt
python3 tonz_model.py
```

## 출력 구성

1. 결정론적 BEP / 완제선 (고정비 58~75억 시나리오, 무이자·6% 이자)
2. 물리적 환자 수용력 역산 그리드 (의사당 일환자 × 객단가 → 매출·실수령·완제 소요)
3. 몬테카를로 (월 단위 15년: 램프업, 계절성, 의사 이탈, 창업자 이탈, 번아웃, 법적 리스크)
4. 단일 변수 민감도 분석
