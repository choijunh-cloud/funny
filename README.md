# 8월 18일 NON-삼전닉스 강의 노트

당일 Quick 코멘트를 영상 녹화용 워드 문서로 재구성한 정리본입니다. 원문 숫자는 유지했고, 추정은 보태지 않았습니다.

## 파일

- [`docs/8월 18일 NON-삼전닉스 (소부장, SK, 자동차).docx`](docs/8월%2018일%20NON-삼전닉스%20(소부장,%20SK,%20자동차).docx) — 본편
- [`scripts/build_aug18_notes.py`](scripts/build_aug18_notes.py) — 문서 생성 스크립트

## 구성

1. **소부장** — 테스, 한미반도체, 원익IPS (+ 리노공업 당일 코멘트)
2. **SK 지주사** — SOTP, SK에코플랜트 재평가, 실트론 매각
3. **Atlas** — 공장 투입, 현대모비스·현대글로비스
4. **당일 추가** — 메모리 밸류 스케치, Dark GPU

영상 녹화 예정, 당일 오후~저녁 업로드 예상.

## 다시 만들기

```bash
pip install python-docx
python3 scripts/build_aug18_notes.py
```
