# 톤즈 부평점 인수 딜 — 정량 모델

부부 원장이 현금 10억(각 5억)을 넣고, 나머지 **90억을 매출 연동으로 상환**하며,
**매출의 10%를 선취**하고 **90%를 MSO(본사)가 가져가는** 구조.
"6~7년이면 다 갚고 병원이 내 것이 된다"는 전언을 검증하기 위해 만든 모델이다.

대화에서 오간 숫자들(고정비 30억 / 58억 / 70억, 실수령 = 매출×3.1%, 완제 확률 20~70%)이
서로 충돌했기 때문에, 가정을 코드로 고정하고 재현 가능한 형태로 다시 계산했다.

```bash
pip install -r requirements.txt
PYTHONPATH=src python -m tonz_model.cli --paths 30000     # outputs/ 에 리포트 생성
PYTHONPATH=src python -m pytest -q                        # 40개 검증 테스트
```

산출물: `outputs/report.md` (전체), `outputs/summary.md` (한 장), `outputs/results.json` (원자료)

---

## 1. 무엇을 고쳤나 — 이전 계산들의 문제

| 이전 계산 | 문제 | 이 모델의 처리 |
|---|---|---|
| 고정비 "연 30억 / 58억 / 70억" | 무엇이 고정인지 미정의. 봉직의 보수를 고정비로 넣었다 뺐다 함 | 항목별 분해. 봉직의는 **준변동비**(최저보장 vs 인센티브 중 큰 값) |
| "1인 세후 = 월매출 × 3.1%" | 선형 계수. 누진세를 무시해 고매출 구간을 과대평가 | 종합소득세 누진 + 지방세 + 연금 + 건보(상한) 실계산 |
| "매출 90%로 갚는다" | 상환여력이 매출에 90% 비례한다는 착시 | 한계 상환기여는 저매출 구간 **57%**, 고매출 구간 **34%** (인센티브·변동비 때문) |
| "의사 10명 × 하루 N명" | 공급만 있고 수요가 없음. 수요 부진 시 감원 대응이 없어 하방 과장 | **수요를 1차 상태변수로** 두고, 의사·직원을 수요에 맞춰 리사이징 |
| 매출 가정이 매번 바뀜 | 5.3억 → 6.4억 → 8.3억 → 9.0억 | 실사 앵커(연 82/110/145억)를 p15/p50/p85로 놓고 로그정규 **캘리브레이션** |
| 폐업 시 소득 0 | 하방 과장 | 폐업 후 **봉직의 복귀 소득**을 깔아줌 |

## 2. 구조

```
수요(환자수)  ──┐
              ├─► 실제 진료 = min(수요, 의사 병목, 시설 병목, 인력 병목)
공급(의사/직원)─┘            │
                             ├─► 매출 = 진료수 × 객단가
                             │
매출 ─┬─ 10% 부부 선취 ──► 종합소득세·4대보험 ──► 세후 실수령
      └─ 90% MSO ─┬─ OPEX(직원50 + 봉직의 + 임대 + 마케팅 + 재료·수수료)
                  └─ 남으면 원금 90억 상환 ──► 완제 시 소유권 이전
```

이벤트: 봉직의 이탈/충원, 창업자(황아름) 이탈, 부부 번아웃(월 2일 휴무의 지속성),
가격 경쟁, 의료사고(세데이션 포함), 사무장병원 적발, 명의자 과세 리스크,
누적 적자에 따른 선취율 재협상, 폐업.

| 모듈 | 역할 |
|---|---|
| `params.py` | 모든 가정. 관측치 / 업계추정 / 판단 을 주석으로 구분 |
| `calibration.py` | 매출 앵커 → 수요 prior 적합 |
| `capacity.py` | 3중 병목으로 물리적 매출 천장 계산 |
| `costs.py` | 고정 / 준변동 / 변동 분해 |
| `deterministic.py` | BEP, 기간별 필요매출, 실수령 (닫힌 형태) |
| `simulate.py` | 30,000경로 × 120개월 몬테카를로 |
| `scenarios.py` | 시나리오·스트레스·토네이도·역산 |
| `feasibility.py` | '도달 가능'과 '유지 가능'의 분리 |
| `career.py` | 응급의학 잔류(D-N-Off×4) vs 딜 |

## 3. 핵심 결과

**손익분기**

- 병원 자체 손익분기(매출 = OPEX): **월 7.8억**
- 부부 10% 선취를 얹은 상환 손익분기: **월 9.2억** ← 실사 앵커 중앙값(월 9.17억)과 거의 같다
- 7년 완제선 **월 11.4억**, 6년 완제선 **월 11.8억** (무이자 가정, 이자 6%면 각각 12.0억 / 12.5억)

즉 **추정 매출 중앙값에서 상환여력이 0 근처**다. 이게 이 딜의 전부다.

**확률 (몬테카를로 30,000경로)**

| | 확률 |
|---|---|
| 6년 내 완제 | 7% |
| 7년 내 완제 | 8% |
| 10년 내 완제 | 11% |
| 10년 내 폐업·적발로 종료 | 49% (5년 내 18%) |
| 월 2일 휴무를 10년간 유지 | 13% (중앙 2.8년에 깨짐) |

**부부 실수령** — 병원이 도는 동안 부부 합산 세후 월 **약 4,000만원**(p10 2,100 / p90 6,300).
1인 환산 약 1,900만원. 월 268시간 기준 시간당 **7.0만원**.

**도달과 유지는 다른 질문**

| 목표 | 필요 월매출 | 단년도 달성 | 그 기간 유지 | 실제 완제 |
|---|---|---|---|---|
| 10년 완제 | 10.5억 | 31% | 20% | 11% |
| 7년 완제 | 11.4억 | 22% | 15% | 8% |
| 6년 완제 | 11.8억 | 18% | 12% | 7% |

단년도로는 p<0.05로 기각되지 않는다("불가능"이 아니다).
확률을 죽이는 건 **6~7년 연속 유지**다.

**무엇이 참이어야 반반이 되는가** — 단독 레버로는 객단가 20.5만원(현재 추정의 1.46배)뿐이고,
수요·직원수·선취율은 단독으로 50%에 도달하지 못한다.
조합으로는 **실측 매출이 연 150억대**(월 환자 9,800명 × 객단가 16만)일 때 7년 완제 확률이 약 58%가 된다.
→ 실사 보고서의 "결정적 스위치: 최근 12개월 실측 매출 145억 이상인가"와 같은 지점에서 만난다.

## 4. 계약서 한 줄이 만드는 차이

| 조항 | 7년 완제 | 부부 세후 월수령 |
|---|---|---|
| 기준 (무이자 90억 캡) | 8% | 4,000만 |
| 이자 6% | 6% | 4,000만 |
| '매출 90%'가 아니라 '정산이익의 90%' | 22% | **326만** |
| 운영 적자를 명의자(부부)가 메움 | 8% | **2,026만** |

'90%의 정의' 한 줄이 부부 월수령을 4,000만에서 326만으로 바꾼다.
'적자를 누가 메우는가' 한 줄이 그것을 절반으로 자른다.

## 5. 한계

- 계약서 원문을 못 봤다. 이자·연대보증·잔액 처리·90%의 정의는 **가정**이며, 각각 시나리오로 처리했다.
- 실측 매출·환자수·객단가를 못 봤다. 매출 prior는 3개 앵커에 대한 로그정규 적합이다.
- 사무장병원 적발, 폐업, 번아웃 해저드는 판단 기반 prior다. 토네이도에 포함해 영향도를 명시했다.
- 세금은 개인사업자 기준이다. 법인 전환이나 MSO 지급분의 필요경비 인정 여부에 따라 크게 달라진다
  (후자는 `tax_attribution` 이벤트로 별도 반영).
- 모델은 의료사고의 인적 피해나 면허 리스크를 금액으로 환산하지 않는다.

숫자 네 개(최근 12개월 실측 매출, 이자 조항, 연대보증, 90%의 정의)가 확인되면
`params.py`만 고쳐서 다시 돌리면 된다.
