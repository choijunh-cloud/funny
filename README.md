# 톤즈 부평점 인수 딜 정밀 모델

부부 10억 + MSO 90억, 매출 10% 선취 / 90% 상환 구조의 손익·실수령·엑시트 추정.

## 한 줄 결론

월급(선취 10%)은 나올 가능성이 높다. **6~7년 완제 임계는 월 11.2~11.5억**(고정 68억·변동 30%).

- 공개 데이터 prior(중앙 7.6억): 7년 완제 **약 9%**, 부부 실수령 중앙 **약 3,900만**
- 의자 용량이 차는 조건부(의사당 25명·객단가 15만 → 월 11.55억): 엑시트 **약 5.9년**, 부부 **약 5,800만**. 용량 조건부 MC 7년 완제 **약 37%**

스위치는 최근 12개월 실측 매출이 월 10억을 넘는지다.

## 실행

```bash
python3 -m pip install -r requirements.txt
python3 -m pytest -q
python3 -m tonz_model
```

결과: `outputs/ESTIMATE.md`, `outputs/estimate.json`, 차트 PNG.

## 항등식

```
연 상환여력 = 연매출 × (0.90 − 변동비율) − 연고정비 − 연이자
1인 세후 = 누진 종소세 + 지방세 10% + 건보 7.19% + 장기요양 + 국민연금(상한)
```

대화에 쓰인 `1인 세후 = 월매출 × 3.1%`는 실효세 38% 고정 근사라, 고매출에서 실수령을 과대평가한다.

## 권장 가정

| 항목 | 값 | 근거 |
|---|---|---|
| 고정비 | 연 68억 | 페이닥터 9 + 직원 50 + 338평 임대 |
| 변동비 | 매출 30% | 재료 20~25% + 카드 + 변동 마케팅 |
| 면적 | 1,119㎡ (338평) | 공공 인허가. 500평은 마케팅 |
| 의사 | 일반의 11, 전문의 0 | 심평원 |
| 매출 prior | 로그정규 중앙 7.6억 | 부평 평균 1.21억 × 규모 보정. 150억 자기신고는 꼬리 |
