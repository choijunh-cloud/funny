## 합성 방법

1. **12mf PBR 35%** — 키움 프레임, 배수는 iM 0.25x와 키움/대신 0.30x의 절충 **0.28x**
2. **SOTP 25%** — 투자자산(모비스 등)은 시가, 제철 장부는 0.17x
3. **EV/EBITDA 15%** — 2026E EBITDA 중위 × 6.2x − 순차입. 미국 피어 7.1x는 배제
4. **증권사 품질가중 25%** — 한화·iM 가중 ↑, 하나 ↓
