## 6. Agentic 메모리

- 128K Context (70B 예시) ≈ **40GB KV** = 2×80 Layer×8 Head×128 Dim×2B × 128K
- Agent 1/2/4/8/16 = 40/80/160/320/640GB. Agent 4개면 KV 160GB, HBM 192GB에 32GB만 남음
- Total Agent State ≈ 500GB는 KV + Tool/검색/중간추론/메시지 등 **가정 시나리오** (공식 아님)
- Concurrent KV 160→480→1,000GB · State 500GB→2TB · HBM 192→576GB. State > HBM
- 병목은 대역폭보다 **용량**. Active Working Set은 일부
- Tiering: HBM(Hot) → DRAM 1~2TB(Warm) → CXL 수TB(Cold)
- HBM이 DRAM을 대체하는 게 아니라, HBM 부족 → DRAM·CXL 수요↑
- KV Churn + Tool calling이 동시에 높으면 용량+트래픽. Overlap 0% = GPU Stall
- DPC: 1DPC 속도(예 DDR5-6400) · 2DPC 용량(예 5600). 12ch×1DPC×128GB=1.5TB, ×2DPC=3TB
- 채널↑ = 핀·전력·비용↑ → CXL. CPU Q 둔화에도 DRAM 수요는 늘 수 있음
