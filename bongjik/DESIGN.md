# 봉직 통합 모델 v3 — 학습과 구조

응급의학과 봉직 공고를 여수 단독 레이더(2026-05)에서
72프로필 실측 마스터(2026-08-18)까지 쌓아 온 자료를 **하나의 추정기**로 묶는다.

현직 앵커는 나사렛국제(통장 실측 2,800 · 입원 97/274).
거주지 기본값은 옥수동. 통근 표만 갈아끼우면 다른 주소로 옮길 수 있다.

---

## 1. 자료가 말해 준 것

### 1.1 점수가 진화한 이유

| 단계 | 점수 정의 | 잘한 점 | 깨진 점 |
|---|---|---|---|
| 여수전남 단독 | 레이더 6축 주관 | 후보자 적합/부적합을 먼저 나눔 | 시장 비교 없음. Gross↔Net이 쉽게 틀림 |
| 12곳 | 8축 주관 평균 | 프로파일별 추천 | 점수 = 인상. 적십자가 워라밸 1순위 |
| 24곳 | Net / 1인당 환자 | 가성비 한 줄 | 환자 적은 곳이 자동 1위 → 1,500명 플로어 |
| 42–60곳 | 풀 확장 + 권역 요약 | 시장 스케일 | 점수 정의는 그대로 |
| 61곳 월수령순 | 통장 절대값 | 「월 3,000만+ ≈ 지방」 | 서울 거주자에게 잘못된 1위 |
| v4.8 | 단가 70% + Net 30% − 리스크 − 통근 | 함정을 감점. 거주지 표 교체 | 통근을 「좋은 병원」에 섞음 |
| v5.1 | 안전·로딩·페이·시스템·워라밸 + 중증도 | 백업 불신, 유효시간당 | 페이 가중 낮아 경희 고정 1위 |
| v1.2 코드 | 인센 보정 통장, 4프로필 평균순위, 단가 13.3 | 실측 오버라이드, 신규 카드, 통계 컷 | 컷은 표본 내 설명값. L2는 pp 경유 |
| 시트38 조건 v2 | 2단 게이트 + 연환자 3분법 + S1–S5 | 「공고 뜨면 게이트부터」 | 정성이 점수에 없음. 프레임 A/B 충돌 |
| 8월 시트40–43 | 홀드아웃 5+3건 | 함정 3분법 실전, 출장형, S6, NMC | 병렬 세션이 마스터를 계속 추가 |

핵심 교훈은 하나다. **단일 종합점수는 가중치만 바꿔도 1위가 바뀐다.**
몬테카를로가 이미 보여 줬다. 경희는 어떤 가중치에서도 상위, 적십자는 1위~29위.

### 1.2 숫자로 남은 「좋은 조건」

| 게이트 | 역할 | 성능(시트38, n=70) |
|---|---|---|
| 안전 ≥ 6.3 | 최강 단일 스크리닝 | F1 0.81 · 재현 0.85 |
| 워라밸 ≥ 6.14 | 통과하면 거의 맞음 | 정밀 0.86 · 재현 0.60 |
| 보정단가 ≥ 13.3 | 세 라벨이 같은 컷에 수렴 | 설명적 컷. 예측 임계값 아님 |
| 스크리닝 | 안전≥6.3 **그리고** 단가≥11.1 | F1 0.79–0.81 · 정밀 83–88% |
| 확정 | 안전≥5.5 **그리고** 단가≥13.1 | 정밀 87–93% |
| 연환자 3분법 | <15,000이면 원인 확인 | 권역축소·국공립신설은 구제, 배후부실은 탈락 |
| 8월 추가 | 대학구조는 **경계** (구제 아님) | 고신대 연 10,102 |
| 보조 | 월≤130h · 시간당≤2.0 · 출근≤12회 | 재현용 |
| 거부 | 안전 < 4.0 | 8월 동의(3.5)에서 승격 |

함정 패턴.

- **고단가 함정**: 환자 극소(적십자 734명) → 단가 51만. 24곳 시절부터 분모 플로어가 필요했다.
- **고액 그라인더**: 여수전남 통장 2,626→2,770 · 1인당 3,432 · 단가 9.7.
- **DC 포함 함정**: 액면 Net을 13으로 나누면 −8%. 안양샘·유비스·검단탑·천안충무.
- **소풀 도미노**: 수원의료원 6인 연쇄 이탈 (8월 재공고).
- **즉시마감**: 김포우리·남원 — 시장이 먼저 검증한 매물.

### 1.3 8월이 새로 남긴 것

- **출장형**: 포항세명 DDNN 7연속오프 · 천안충무 3근무-5오프+1년 고정표 · 진주 월 10회.
  통근 제약을 우회한다. 페이가 좋아서가 아니다.
- **S6 근무표 예측가능성**: 정성 신호 6번째. 비용 제로 협상 카드.
- **NMC**: 옥수 15–25분으로 전 풀 통근 최상위. 통장 ~2,150이면 단가 9–10.
  같은 값의 강북삼성(단가 14.1 · 안전 8.6 · 96h)이 우월전략.
  전공의 복귀 → 과장 연봉삭감 후문은 수련병원 페이 하방의 첫 실측 사례.
- **검단탑**: 수도권 물량형. vs 나사렛은 손해 거래. 수확은 KTAS/ICU 가중 인센 설계.
- **이중 진실 수리**: 시트1 통장이 인센포함 열에 붙어 있으면 모델 입원인센을 재가산하지 않는다.
  NMC·제주한라가 이 규칙의 대상. 경희·이대목동은 기본 열에 붙어 있어 모델 인센을 더한다.

### 1.4 프로파일이 다른 이유

- 옥수동 균형: 경희 · 순천향서울 · 고대안암 · (통근만 보면 NMC)
- 통장 절대값: 진주 · 여수제일 · 동강 (이주 전제)
- 워라밸: 동강 야간전담 · 강원대 3교대 · 고대 96h
- 권역 커리어: 진주 · 안동 · 이대목동
- 사학연금: 고대 · 이대목동 · 강동경희 · 원광산본
- 저중증 안전: 강북삼성
- 출장형: 포항세명 · 천안충무 · 진주

현직 나사렛(워라밸 3.97)은 어떤 가중치로도 상위 15에 못 들어 이직 동기가 수학적으로 성립한다.

## 2. 기존 모델을 그대로 쓰면 안 되는 지점

1. **프레임 충돌** — 프레임 A(4프로필)는 진주 > 경희. 프레임 B(v5.1)는 경희가 버틴다. 「1위 교체」를 확정처럼 쓰지 않는다.
2. **페이 누출** — L2「페이 제거」도 환자당 단가(pp)를 로딩 축과 공유한다.
3. **컷의 지위** — 13.3은 설명적 기준. 시점 외 공고가 경계(11–16)에 몰리면 보조 라벨 유의성이 죽는다 (시트38가 이미 약화).
4. **통근 혼입** — v4.8은 옥수동 보정을 병원 점수에 더해 지방 우량 병원을 깎는다.
5. **정성 미계량** — S1–S6과 즉시마감/조건상향/재공고는 세션에서 실증됐지만 시장 랭킹을 뒤집지 않게 상한을 둔다.
6. **데이터 위생** — 시나리오 행(을지 10/12, 적십자 병당 O/X)과 물리기관을 같은 n으로 세면 컷이 흔들린다. 베스티안은 ER 봉직이 아니다.
7. **이중 진실** — 코드 오버라이드와 시트1 통장이 어긋나면 진주/경희 순위가 파일마다 달라진다. v3는 시트 열 근접으로 인센 포함 여부를 추론한다.

## 3. v3 구조

점수를 하나 더 만들지 않는다. **층을 나눈 추정기**다.

```text
공고 원문
   │
   ▼
[0] 위생     물리기관 vs 시나리오 · 실측/시트인센포함/모델추정 · ER 범주외
   │
   ▼
[1] 거부     법적 D · 월≥168h · 안전<4.0 · 한산+약백업 · 회피 리스트
   │
   ▼
[2] 스크리닝  안전≥6.3 AND 단가≥11.1
   │
   ▼
[3] 확정     안전≥5.5 AND 단가≥13.1 + 연환자 3분법
   │
   ▼
[4] 보조     월≤130h · 시간당≤2.0 · 워라밸 신호
   │
   ▼
[5] 시장점수  프레임 A(4프로필)와 프레임 B(v5.1)를 나란히
   │
   ▼
[6] 정성     S1–S6 + 즉시마감/조건상향/재공고/출장형
   │
   ▼
[7] 개인화   옥수동 통근 · 커리어 · 연금 · 평판
   │
   ▼
[8] 카드     판정 · 시장가 잔차 · 목표구간 갭 · 컨택 질문
```

### 3.1 판정 라벨

| 라벨 | 의미 | 다음 행동 |
|---|---|---|
| `AVOID` | 거부 게이트 또는 회피 리스트 | 시간 쓰지 않음 |
| `PASS_CONFIRM` | 확정 콤보 + 연환자 통과/구제 | 컨택 1순위 |
| `PASS_SCREEN` | 스크리닝만 통과 | 후보. 단가·백업·연환자 원인 확인 |
| `HOLD` | 숫자 일부만 좋음 | 프로파일이 맞을 때만 보관 |

### 3.2 보정 통장

```text
월환자 = 1인당연환자 / 12
입원인센(모델) = 월환자 × 0.354 × 중증도 × 3만
보정통장 = 통장 + 인센     (실측·실측포함·시트인센포함이면 재가산 금지)
보정단가 = 보정통장 / 월환자
가용현금 = 보정통장 × 12/13   (DC 포함일 때만)
```

앵커는 나사렛 실측 입원 97/274. 순수 추정은 실측 2,800 대비 2% 안쪽이어야 한다.

### 3.3 시장가 잔차

```text
기대단가 = median(보정단가 | 권역그룹, 백업그룹)
잔차(만/명) = 실제단가 − 기대단가
잔차통장 = 잔차 × 월환자
```

고단가 함정(연환자 < 8,000 · 백업 약)은 잔차가 커도 `AVOID`/`HOLD`를 우선한다.

### 3.4 의도적으로 하지 않는 것

- 가중치 최적화로 「진짜 1위」를 찾는 일.
- 컷 13.3을 예측 임계값으로 고정.
- 통근 시간을 전국 랭킹에 더하는 일.
- 공고에 없는 연환자·Net을 댓글 감각으로 채워 랭킹에 넣는 일.
