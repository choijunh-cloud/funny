# JobFit v2 — 좋은 병원 구직 조건 추정

응급의학과 봉직 공고를 12곳(주관 레이더)에서 70프로필(실측 통합)까지 쌓아 온
마스터·백업·v4.8·v5.1·v1.2 코드를 학습한 뒤, **다음 공고가 떴을 때
「좋은 조건인가」를 추정하는 의사결정 모델**을 구상한다.

기준일: 마스터 2026-07-17 (물리기관 68 · 프로필 70+). 현직 앵커는 나사렛국제.

---

## 1. 자료가 말해 준 것

### 1.1 모델이 진화한 이유

| 단계 | 점수 정의 | 잘한 점 | 깨진 점 |
|---|---|---|---|
| 여수전남 단독 | 레이더 6축 주관 | 후보자 적합/부적합을 먼저 나눔 | 시장 비교 없음 |
| 12곳 | 8축 주관 평균 | 프로파일별 추천이 생김 | 점수 = 인상 |
| 24곳 | Net / 1인당 환자 | 가성비 한 줄 | 환자 적은 곳이 자동 1위 → 1,500명 플로어를 급히 넣음 |
| 61곳 월수령순 | 통장 절대값 | 「월 3,000만+ = 거의 지방」 발견 | 서울 거주자에게 잘못된 1위 |
| v4.8 | 단가 70% + Net 30% − 리스크 − 통근 | 함정(적십자·병당)을 감점으로 처리 | 통근을 「좋은 병원」에 섞음. 적십자가 여전히 점수 1위 |
| v5.1 | 안전·로딩·페이·시스템·워라밸 + 중증도 | 백업 불신, 유효시간당 | 페이 가중 낮아져 경희가 고정 1위. 이후 진주 실측이 들어오면 프레임이 갈라짐 |
| v1.2 코드 | 인센 보정 통장, 4프로필 평균순위, 단가 13.3 | 실측 오버라이드, 신규 공고 카드, 통계 컷 | 컷은 표본 내 설명값. L2는 pp 경유로 페이와 완전 독립이 아님 |
| 시트38 조건 v2 | 2단 게이트 + 연환자 3분법 + S1–S5 | 「공고 뜨면 게이트부터」 | 정성 신호가 점수에 안 들어감 |

핵심 교훈은 하나다. **단일 종합점수는 가중치만 바꿔도 1위가 바뀐다.**
몬테카를로(시트7)가 이미 보여 줬다. 경희는 어떤 가중치에서도 상위, 적십자는 1위~29위.

### 1.2 숫자로 남은 「좋은 조건」

마스터 71행 분포(소방 잠정·베스티안 포함):

- 통장 중앙 2,333만 · Q3 2,530만 · 최댓값 진주 3,367만
- 1인당 환자 중앙 2,554 · 월시간 중앙 122h
- 연환자 중앙 20,864 (Q1 14,000)

시트25·38이 라벨(종합 TOP20 / QOL 게이트)로 다시 쪼갠 판별력:

| 게이트 | 역할 | 성능(당시) |
|---|---|---|
| 안전 ≥ 6.3 | 최강 단일 스크리닝 | F1 0.81 · 재현 0.85 |
| 워라밸 ≥ 6.14 | 통과하면 거의 맞음 | 정밀 0.86 · 재현 0.60 |
| 보정단가 ≥ 13.3 | 세 라벨이 같은 컷에 수렴 | 설명적 컷. 예측 임계값 아님 |
| 스크리닝 콤보 | 안전≥6.3 **그리고** 단가≥11.1 | F1 0.81 · 정밀 88% |
| 확정 콤보 | 안전≥5.5 **그리고** 단가≥13.1 | 정밀 93% |
| 연환자 3분법 | <15,000이면 원인 확인 | 권역축소·국공립신설은 구제, 배후부실은 탈락 |
| 보조 | 월≤130h · 시간당≤2.0 · 출근≤12회 | 재현용 |

함정 패턴도 반복된다.

- **고단가 함정**: 환자 극소(적십자 734명) → 단가가 51만으로 폭등. 24곳 시절부터 분모 플로어가 필요했다.
- **고액 그라인더**: 여수전남 통장 2,626~2,770 · 1인당 3,432 · 단가 9.7. 페이로 순위를 사면 안 된다.
- **DC 포함 함정**: 액면 Net을 13으로 나누면 −8%. 안양샘·유비스.
- **소풀 도미노**: 수원의료원 6인에서 연쇄 이탈.
- **즉시마감**: 김포우리·남원 — 시장이 먼저 검증한 매물.

### 1.3 프로파일이 다른 이유

의사결정 매트릭스는 「좋은 병원 1위」가 아니라 **사는 곳·원하는 삶**으로 1위가 갈린다.

- 옥수동 균형: 경희 · 순천향서울 · 고대안암
- 통장 절대값: 진주 · 여수제일 · 동강 (이주 전제)
- 워라밸: 동강 야간전담 · 강원대 3교대 · 고대 96h
- 권역 커리어: 진주 · 안동 · 이대목동
- 사학연금: 고대 · 이대목동 · 강동경희
- 저중증 안전: 강북삼성 (LIGHT & SAFE 스윗스팟)
- 8월 신설 렌즈: 출장형 (연속 오프 · 야간 수면 · 원거리 통근 실존)

현직 나사렛(통장 실측 2,800 · 1인당 3,114 · 워라밸 3.97)은
어떤 가중치로도 상위 15에 못 들어 이직 동기가 수학적으로 성립한다.

## 2. 기존 모델을 그대로 쓰면 안 되는 지점

1. **프레임 충돌** — 4프로필 평균(프레임 A)은 진주 90 > 경희 88.
   v5.1 공식(프레임 B)은 경희 93 > 진주 84. 「1위 교체」를 확정처럼 쓰면 안 된다.
2. **페이 누출** — L2「페이 제거」도 환자당 단가(pp)를 로딩 축과 공유한다. 완전 독립 라벨이 아니다.
3. **컷의 지위** — 13.3은 현재 풀에서 라벨 3종이 반복 관찰한 **설명적 기준**이다.
   시점 외 공고가 쌓이기 전에 예측 임계값으로 부르지 않는다.
4. **통근 혼입** — v4.8은 옥수동 보정을 병원 점수에 더해 지방 우량 병원을 깎는다.
   「시장에서 좋은 자리」와 「내가 출근할 자리」는 따로 둬야 한다.
5. **정성 신호 미계량** — S1 결원헤지 · S2 인센표 · S3 운영디테일 · S4 불가과 자백 · S5 퇴직금 방식은
   세션에서 실증됐지만 랭킹에 없다.
6. **데이터 위생** — 시나리오 행(을지 10인/12인, 적십자 병당 O/X)과 물리기관을 같은 n으로 세면
   컷 p값이 흔들린다. 베스티안(화상·주간)은 ER 봉직이 아니다.
7. **이중 진실** — 코드 오버라이드와 시트1 통장이 어긋나면 진주/경희 순위가 파일마다 달라진다.

## 3. JobFit v2 구조

점수를 하나 더 만들지 않는다. **층을 나눈 추정기**다.

```text
공고 원문
   │
   ▼
[0] 위생     물리기관 vs 시나리오 · 실측/추정 · ER 범주외 제외
   │
   ▼
[1] 거부     법적 D · 월≥168h · 약백업+한산 · 회피 리스트
   │
   ▼
[2] 스크리닝  안전≥6.3 AND 단가≥11.1          ← 재현 (놓치지 않기)
   │
   ▼
[3] 확정     안전≥5.5 AND 단가≥13.1 + 연환자 3분법  ← 정밀 (허탕 방지)
   │
   ▼
[4] 보조     월≤130h · 시간당≤2.0 · 워라밸 신호
   │
   ▼
[5] 시장점수  4프로필 평균순위 (통근 없음)     ← 「시장에서 좋은 자리」
   │
   ▼
[6] 정성     S1–S5 + 즉시마감/조건상향/재공고
   │
   ▼
[7] 개인화   옥수동 통근 · 커리어 · 연금 · 평판   ← 「나에게 좋은 자리」
   │
   ▼
[8] 카드     판정 · 시장가 잔차 · 목표구간 대비 갭 · 컨택 질문
```

### 3.1 판정 라벨 (랭킹보다 먼저)

| 라벨 | 의미 | 다음 행동 |
|---|---|---|
| `AVOID` | 거부 게이트 또는 회피 리스트 | 시간 쓰지 않음 |
| `PASS_CONFIRM` | 확정 콤보 + 연환자 통과/구제 | 컨택 1순위. 체크리스트만 확인 |
| `PASS_SCREEN` | 스크리닝만 통과 | 후보. 단가·백업·연환자 원인 확인 |
| `HOLD` | 숫자 일부만 좋음 | 프로파일이 맞을 때만 보관 |

### 3.2 시장 점수와 개인 점수

- **시장 점수**: v1.2와 같은 4프로필(균등 / QOL / 균형 / 현금) 평균순위.
  거주지 보정을 넣지 않는다. 진주와 경희를 같은 척도에서 비교할 수 있다.
- **개인 점수**: 시장 점수 + 통근 가감 + 정성 가점 + 평판 감점.
  옥수동 기본값. 거주지를 바꾸면 통근 표만 갈아끼운다.

1위 다툼은 「어떤 점수인가」를 항상 밝힌다.
서울 거주 균형형이 물을 때는 개인 점수를, 전국 이주를 전제하면 시장 점수를 본다.

### 3.3 보정 통장 (v1.2 유지)

```text
월환자 = 1인당연환자 / 12
입원인센(모델) = 월환자 × 0.354 × 중증도 × 3만
보정통장 = 통장 + 인센   (실측포함이면 재가산 금지)
보정단가 = 보정통장 / 월환자
```

앵커는 나사렛 실측 입원 97/274. 오차는 실측 2,800 대비 2% 안쪽이어야 한다.
DC 포함 표기는 `×12/13`로 가용 현금을 따로 보여 액면 −8%를 숨기지 않는다.

### 3.4 시장가 잔차 — 「이 페이가 좋은가」

단가 13.3은 컷이지 공정가격이 아니다. 같은 권역·백업 티어의 중앙 단가와 비교한다.

```text
기대단가 = median(보정단가 | 권역그룹, 백업그룹)
잔차(만/명) = 실제단가 − 기대단가
잔차통장 = 잔차 × 월환자
```

잔차 > 0 이면 시장 대비 후한 공고, < 0 이면 싼 공고다.
고단가 함정(연환자 < 8,000 · 백업 약)은 잔차가 커도 `AVOID`/`HOLD`를 우선한다.

### 3.5 목표 조건 구간 — 「뭘 보고 지원하나」

확정 통과 집합의 사분위수로 **프로파일별 목표 밴드**를 추정한다.
신규 공고는 이 밴드와의 갭으로 읽는다.

| 프로파일 | 핵심 필터 | 보는 숫자 |
|---|---|---|
| 서울균형 (기본) | 서울·수도권 + 확정 | 단가·안전·통근·월시간 |
| 현금 | 전국, 통장 상위 | 보정통장 · 이주 비용 |
| 워라밸 | 월≤122 · 워라밸≥5.4 | 시간 · 야간휴식 · 출근횟수 |
| 커리어 | 권역·상종·외상 | 시스템 · 전공의 · 중증도 |
| 라이트세이프 | 중증≤1.0 · 안전≥5.5 | 함정(한산+약백업) 제외 |
| 출장형 | 월≤120 + 연속오프/야간수면 | 근무횟수 · 원거리 가능성 |

밴드 밖의 공고를 자동 탈락시키지 않는다. **갭을 보여 주고 협상/검증 항목으로 바꾼다.**

### 3.6 정성 신호 (가점은 작게)

| 코드 | 신호 | 왜 중요한가 |
|---|---|---|
| S1 | 결원 헤지 명문화 | 급여 하방 보호 (제주 인원별 표, 오산 1/n) |
| S2 | 인센 단가표 공개 | 투명성 = 신뢰 (김포 MRI/CT) |
| S3 | 운영 디테일 | 인계 분리·야간 휴식 — 즉시마감 공통항 |
| S4 | 불가 진료과 자백 | 정직한 공고가 협상도 정직 |
| S5 | 퇴직금 방식 명시 | DC포함 vs 별도. 액면 함정 방지 |
| M | 즉시마감 / 조건상향 / 재공고 | 검증된 매물 vs 안 팔리는 매물 |

정성 가점은 개인 점수에만 더하고, 시장 랭킹을 뒤집지 않게 상한을 둔다.

## 4. 신규 공고 판독 프로토콜

1. **숫자 채우기** — 연환자, EM 인원, 월시간, 통장(퇴직 포함 여부), 백업 주장.
   없으면 추정하지 말고 결측으로 둔다. 여수 분석 때 Gross↔Net 환산이 얼마나 틀리는지 이미 봤다.
2. **거부** — 법적 회색, 월 168h+, 회피 리스트.
3. **단가·안전 게이트** — 스크리닝/확정. 연환자 <15,000이면 3분법(권역축소 / 국공립신설 / 배후부실).
4. **시장가 잔차** — 같은 권역·백업 중앙값 대비 +/−.
5. **프로파일 밴드** — 서울균형 기본. 이주 가능하면 현금·커리어 밴드를 옆에 깐다.
6. **정성 5종** — 없으면 컨택 질문이 된다.
7. **현직자 2명** — 을지·적십자 유형은 숫자 통과여도 통화 전 확정 금지.

체크리스트는 v4.8 포터블과 같다. 통장 3개월, 인센 단가, 인계/야간휴식, 결원수당, 퇴사율.

## 5. 의도적으로 하지 않는 것

- 가중치 최적화로 「진짜 1위」를 찾는 일. 표본 70에서 과적합이다.
- 컷 13.3을 예측 임계값으로 고정. 신규 공고가 경계(11~16)에 몰리면 보조 라벨 유의성이 바로 죽는다.
- 통근 시간을 전국 랭킹에 더하는 일.
- 공고에 없는 연환자·Net을 댓글 감각으로 채워 랭킹에 넣는 일.

대신 **게이트의 정밀/재현**, **잔차의 부호**, **밴드 대비 갭**을 공개한다.

## 6. 다음에 쌓아야 할 검증

- 시점 외: 8월 배치 5건(동의·고신·여수전남 갱신·포항세명·남원)을 hold-out으로 다시 채점.
- 라벨 × 컷 permutation max-stat (v1.2가 남긴 숙제).
- 실측 통장이 늘어날 때마다 오버라이드와 시트1을 한곳으로.
- 출장형 렌즈: 월 근무횟수·연속오프를 구조화 컬럼으로 승격.

이 저장소의 `jobfit_v2.py`는 위 층을 그대로 실행한다.
랭킹표는 참고이고, 출력의 주인공은 **판정 라벨과 목표 조건 밴드**다.
